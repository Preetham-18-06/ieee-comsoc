# IEEE ComSoc JSSATEB website starter

A responsive, static website concept for the IEEE Communications Society Student Chapter at JSS Academy of Technical Education, Bengaluru. The design takes inspiration from the reference IEEE student-branch website but uses its own layout and styling.

## Run locally

1. Extract the folder if downloaded as a ZIP.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.
3. No build step, framework, or package installation is required.

## Project files

- `index.html` — page structure and content
- `styles.css` — responsive styling and layout
- `script.js` — mobile navigation and current year
- `assets/committee-onboarding.jpg` — provided committee onboarding poster
- `assets/ieee-comsoc-logo.png` — cropped IEEE / IEEE ComSoc logo lockup from the poster

## Before publishing

- Confirm committee names and roles are current.
- Add official chapter email, social profiles, event dates, registration links, and faculty details.
- Replace the cropped logo with an official high-resolution brand asset if one is available.
- The poster's embedded logo crop is taken from the supplied image; it is not a vector logo.
- The site uses Google Fonts when online and falls back to system fonts if they are unavailable.
